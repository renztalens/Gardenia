# 🌱 Gardenia: Automated Planting Robot

Gardenia is an Arduino-based automated planting robot designed to assist in greenhouse farming. It systematically plants seeds at consistent intervals, improving efficiency, accuracy, and reducing manual labor.

---
## 🛠️ Built With

- **Arduino Uno** (Microcontroller)
- **C++** (Arduino Programming)
- **Seed Dropper Mechanism**
